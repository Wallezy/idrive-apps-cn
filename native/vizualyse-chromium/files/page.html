Lower draws fewer pixels: faster on the car's processor and lighter on memory, a little blurrier. The page keeps its layout.

More memory lets bigger pages and games load, but leaves less to the car's own screens, which may get slower while a big page runs. Only the browser itself can run out.

The pictures go straight to the car's own screen compositor (Winston): in full colour, and in the GPU mode without copying them back from the graphics card. Compatibility mode sends them through mgu-render instead, as older versions did; the browser does that by itself if Winston can't be reached.

Game mode (experimental): WebGPU stops checking each command a page sends, which saves time in games. Only for sites you trust: a page with mistakes can crash the browser's graphics. Chromium restarts for it, and it is off again whenever the tool starts. While it is on, the other tools are asked to make way: a Steam game stops, and Cast pauses on the cluster and the HUD. A Steam game started later stops the browser until it ends.

GPU mode (experimental): WebGL on the car's own graphics driver instead of the CPU. Chromium restarts for it, and it is off again whenever the tool starts. If the screen ever freezes or goes black, the car restarts and comes back without it.
