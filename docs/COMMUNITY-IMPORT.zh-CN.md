## 运行适配

- RAM 校准保留 ECU 身份核验、新鲜静止车速、停车确认和不自动重发校准命令的约束。
- 仪表夜视只释放自身图层；保留其他应用及原厂图层顺序。查询失败不重设图层；车速缺失、超限或应用心跳过期时停止投射。
- 车辆健康中心缺少数据时显示等待，缺失胎压/保养数据不会被判定为正常。
- 车身高度应用收到无效车速时立即撤销之前的有效车速状态。
- 网页浏览器默认简体中文。保留各渲染客户端原有图像、视频能力。

## 构建与验证边界

应用以 SDK-free source package 发布，车机安装时通过现有链接机制取得本机 SDK；仓库不包含 BMW SDK 或固件。Vizualyse 应用保留原始模块列表和 native RHMI 资源。

部分后台工具沿用来源包内的原始二进制，不宣称重新编译这些二进制。每个工具的 `PROVENANCE.json` / `payload.json` 固定原始包与逐文件哈希；构建只提取校验通过的普通文件，不运行下载的程序。源脚本、服务文件、第三方许可证和本次修改进入 Git。

本地验证覆盖：27 个应用中文/源码打包及可重现检查；22 个画布/校准应用的无网络无车辆启动；6 套渲染客户端各 16 项握手/重连场景；RAM 22 项校准流程；夜视图层清理与车速租约；高度控制的缺失/无效/过期/行驶/断开信号；商店中文字库检查。5 个 Vizualyse 原生页面没有完整车机启动模拟；在线登录、视频解码、实际校准和车型适配未在真车验证。本记录不是实车验证记录。
