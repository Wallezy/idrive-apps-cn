# 简体中文本地化

本仓库是 `robertnisipeanu/idrive-apps` 的国内发行分支，包含一个地图投屏控制应用
和两个原生工具。中文文档、目录说明和应用界面属于不同层次，分别检查。
本页不代表已经通过车机安装、更新、迁移或恢复验收。

## 范围与资源

| 层次 | 资源 | 验证重点 |
| --- | --- | --- |
| 商店目录 | `release/texts/zh-CN.json` | 三个组件均有中文名称与说明，区分控制应用、采集服务和渲染器 |
| 控制应用 | `apps/robertn_waze_cluster/locales/zh-CN.json` 与应用源码 | 原生 HMI 文本、状态、错误和动态提示；保留协议字段、组件 ID 与配置键 |
| 生成资源 | 应用的 `tools/gen_locales.js`、`src/locales.js`、`package/rhmiData` | 使用既有生成器，同步语言资源与应用磁贴 |
| 手机日志页 | `native/waze-on-cluster/patch/logs.js` | 中文页面、空状态和请求错误；归档字节、文件名及原始日志保持不变 |
| 使用文档 | `README.zh-CN.md` | 中文功能说明、真实照片和当前安装状态 |

目录说明同时涵盖 CarPlay、Android Auto、仪表盘及实验性 HUD。
应用名称保留 Waze 品牌，但其能力不限定为 Waze 的 CarPlay 画面。
实际可用地图流仍取决于手机地图应用、连接方式及车机兼容性；
翻译不会增加地图协议能力，也不保证所有地图都提供同样的画面。
手机地图视频里的道路名称、导航提示和地图应用界面由手机提供，本次不对视频内容
做文字识别或自动翻译。

检查命令：

```sh
node release/test/cn_localization_test.js
node apps/robertn_waze_cluster/tools/test_i18n.js
node apps/robertn_waze_cluster/tools/test_page.js
```

第一项检查目录覆盖及版本保持。其余检查使用应用已有的词条、生成资源和页面测试。
本机检查不能替代车机中文字形、截断、动态状态和错误页面的显示验证。

车机语言未知或尚未上报时，国内版控制应用默认简体中文；车机明确选择英语
或其他受支持语言时继续跟随该设置。动态文本仅在展示层翻译，不改变原生服务
用于判断状态的协议值、正则匹配、组件 ID 或控制命令。未知诊断内容显示中文
上下文并保留原文，避免猜测错误含义。手机日志下载页默认简体中文，下载的
日志文件保持原始内容。

## 本次版本保持

本次本地化保持以下数字版本，不追加语言后缀：

| 组件 ID | 版本 |
| --- | --- |
| `robertn_waze_cluster` | `0.6.7` |
| `waze-on-cluster` | `0.9.10` |
| `cluster-render` | `0.5.4` |

基线保存在 `release/cn-localization-versions.json`。检查同时覆盖应用清单、
包描述、锁文件与 RHMI 应用版本，防止只改了一处版本而产生不一致。
以后接纳上游新版本时，应在单独审阅的升级中更新该基线，而不是永久冻结组件。
本次本地化不要运行会增加版本的 `release.js stamp`。

## 同版本不等于自动更新

仅修改 `release/texts/zh-CN.json` 时，可以更新目录中的展示文字，保留安装包的
版本、大小及哈希。车机应用自身的页面和状态文字不会因此自动改变。

修改应用或原生工具中的文字后，安装包字节及哈希会变化。即使数字版本仍相同，
它也不是原安装包，必须区分以下情况：

1. **首次建立国内发行目录。** 尚未发布过的国内目录可以使用保留数字版本的
   国内包，但必须记录对应源码、哈希和发行通道。不能覆盖官方目录或旧镜像包。
2. **已有同版本安装。** 更新器主要比较数字版本。仅切换来源或增加中文目录，
   不会让它自动识别同版本但字节不同的包。首次迁入需经过验证的明确迁移或
   重新安装入口，并保留设置、安装归属与恢复信息；不能把它宣传为普通自动升级。
3. **国内目录已经发布该版本。** 同一组件的同一版本对应唯一制品，禁止覆盖旧包、
   改写既有版本哈希或假装提高版本后再降回去。若需要修改已发布包，必须按正式
   版本策略发布下一版本，并再次验证依赖和恢复流程。

因此，“本次版本号不变”只描述此次准备工作，不是绕过发布规则的办法。
国内目录、安装入口和更新路径通过完整验收前，仍处于开发状态。

因此不能直接套用这一版本方案。
