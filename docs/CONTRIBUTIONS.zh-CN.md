# 应用与组件贡献记录

`release/contributors.json` 是当前发行的署名数据来源。角色按实际保留内容填写；应用作者、翻译、共享代码与发行维护分别记录。

- 独立重译仅在实际替换对应译文后修改翻译署名。当前复用的译文保留其贡献者。
- 共享运行库的许可署名不自动等于每个应用的原创作者或译者。
- 原有 LICENSE、NOTICE 和源码版权声明完整保留，包内 ATTRIBUTION.json 和 CONTRIBUTORS.zh-CN.md 提供中文角色说明。

- Iterio 应用和服务保留原联合作者文字、应用名、图标和许可要求，不添加发行维护者品牌。

包内源码由导入工具调用 `tools/apply_attribution.py` 应用署名；无需连接车辆。版本号由正式发布流程处理。
