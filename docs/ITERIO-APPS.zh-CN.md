# Iterio 应用

转向影像（Turn View）与行车记录（Drive Recorder）的原作者为 IterioDev。
源版本、固定提交、源码包摘要、作者授权确认及原生程序摘要记录在各包的
`PROVENANCE.json`，原许可随包保留。所有者于 2026-11-23 确认取得作者的汉化及分发授权。
原应用名称、图标和署名保留。

## 安装与依赖

从商店安装应用会同时安装配套后台工具，以及声明的部署工具、渲染器依赖。
应用在车机使用现有 SDK 链接构建，仓库不含 BMW SDK、构建后的 app.js、
BMW 字体或 HMI 图标字库。文字使用 Ubuntu、Barlow 与 Noto Sans SC，控件图标使用
源码绘制的矢量图形。界面及状态提示为简体中文，服务标识与消息协议保留原值。
发布范围为 iDrive 7。

Turn View 需要前摄像头（360 环视或前后摄像头），支持仪表和中控画面；
车辆有夜视硬件时可选择夜视输入。每次启动车辆后仪表显示默认关闭，需要手动开启。
仪表中央显示区选择地图视图；与 Waze 仪表地图共用中央区域，使用时将 Waze 设置为
仅 HUD，或关闭 Waze 的仪表输出。应用不会自动修改 Waze 设置。

Drive Recorder 需要车辆摄像头支持行车记录模式。录制、保存、锁定、删除及 USB 导出
使用配套接收和播放服务。播放要求新鲜的静止车速，行驶中暂停；最多保留 4 GB，
超限替换最早的未锁定片段。工具保留上游的配额、摄像头授权配置及原始备份机制。

## 检查

`node tools/test_iterio.js` 检查全部应用页面的离线绘制、中文字形、共享字库分片、
原生程序摘要以及静止播放限制。`node tools/test_localized.js` 检查源码包的确定性、
SDK 缺席和依赖。正式构建在 GitHub Actions 的两台独立构建机上比较摘要。
原生摄像头程序沿用已固定上游的发布文件，摘要可核验；不声称从完整源码重建这些程序。
本次未做真车验证，摄像头、导航和车型兼容性仍需实际运行确认。
