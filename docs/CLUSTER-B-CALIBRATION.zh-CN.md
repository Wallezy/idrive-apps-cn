# ID7 地图下层停车校准

本分支提供离线开发的校准实现，不是已经验证可用的 B 大地图功能。
实际显示范围、缩放、裁切和原厂信息的前后关系仍需实车确认。

## 研究依据

开发基线为 CN `503e0a9`，包含上游 `84e14d6`（cluster-render 0.5.8）；
CN 基线的渲染组件版本为 0.5.9。原研究目录的
`codex/cluster-map-underlay`、未提交研究文档及宿主机探针均独立保留。

2026-11-12 的实车只读基线显示：`map` 为 1088×480、`hud` 为
800×480，均报告 shown；`panel` 为 1920×720、idle。源视频为
1088×480。订阅报告为不可观测，这些状态不证明屏幕最终显示结果。
私人采样保存在仓库外。

参考 [bimmer-lab/apps 的 Cluster Themes](https://github.com/bimmer-lab/apps/blob/66fd6fb844817dd5415dfd6b11b182c059e61c36/apps/cluster_themes/README.md)
和 [shared/waze.js](https://github.com/bimmer-lab/apps/blob/66fd6fb844817dd5415dfd6b11b182c059e61c36/shared/waze.js)：

- 主题自行绘制车速、转速及其他读数；地图接入会请求 `panel`，位于原厂表盘上方。
- 网格和地图开窗校准可帮助观察屏幕坐标。
- README 将原厂警示灯是否仍显示列为待实车验证项。

因此这些主题提供布局和校准思路，没有证明 ID7 的 `map` 下层能够扩展。
本分支没有导入主题代码、资源、SDK 或固件文件。

## 应用入口

仪表地图应用 → 日志 → **地图下层校准（仅限停车）**。

1. 车辆停稳、P 挡、驻车制动已施加；标准仪表地图已正常显示。
2. 勾选停车确认，点击“预览标准网格 · 20 秒”。
3. 标准地图恢复后，再次确认停车，点击“预览扩展网格 · 20 秒”。
4. 随时点击“停止校准”或退出日志页面。

停车确认是用户的主动确认，不是经车辆速度/挡位传感器认证的自动联锁。
每次预览消耗一次确认；返回页面、应用重启、服务重连均不自动恢复预览。
在未展示校准能力的旧渲染服务上，预览入口不可用。

网格间隔为 64 个场景像素，中心为青色十字，四边分别为左红、右蓝、
上黄、下绿，边带宽 12 像素。扩展使用 1632×720；标准使用 1088×480。
网格是一个简单静态着色器，不发送更大的 CarPlay 视频纹理。

## 生命周期与兼容性

- 仅接受 ID7 标准 `map` 配置：槽位 `0x100`，场景 `0x010004f0`，
  class 0，基础尺寸 1088×480，未开启整场景文件。其他配置拒绝启动。
- 普通地图视频必须已显示且仍有帧；另一个校准会话或地图告警存在时拒绝启动。
- 临时画布只用于该 `map` 图形场景的视锥和视口。场景身份、
  `hello.targets`、已有客户端矩形、视频尺寸和持久化设置保持正常配置。
  宽高变化沿用现有场景释放、确认、重新请求流程，可能有短暂等待。
- 静态网格临时占用地图内容；原地图客户端保留其图层并继续接收帧。
  `guide_hold=false` 让原厂转向提示在校准期间有机会显示；不写其保存设置。
- 服务端按单调时钟从接受请求开始计时，最多 20 秒。客户端每 500 ms
  续一次 2 秒租期，续期不会延长总时限。
- 手动停止、连接关闭、租期到期、总时限到期、地图视频消失/停帧、地图告警、
  显示服务不可用，以及校准已映射后的显示中断都会结束校准。
- 结束时移除网格，清除临时尺寸，通过场景管理器恢复标准画布。
  显示服务尚不可用时，需要等它恢复后才可能重新显示标准地图。
- `panel`、HUD 和它们的配置不参与校准。原厂弹窗可能触发车端全局布局变化；
  这是需要实车观察的行为。
- 应用通过 `release.json` 要求同分支渲染器的下一发行版。旧应用继续使用
  原协议；新应用面对旧渲染器会禁用预览。开发分支保留 `next`；
  Beta 发行分支将它解析为同批渲染器的实际版本。

## Beta 更新与回退

本次车主试验使用应用 `robertn_waze_cluster` 0.6.8 和
`cluster-render` 0.5.10。在 CN Beta 的 Store 中更新已有仪表地图应用；
更新器根据应用依赖先更新渲染器。其他组件仅在其已有依赖尚未满足时安装。
按 Store 提示完成重启后，先检查普通地图，再进入停车校准。
更新本身不启动校准。

“停止校准”恢复标准地图画布，软件仍是 Beta 测试版本。
如需恢复上一软件版本，在 Store 的应用详情页选择可用的上一版本回退：
先回退仪表地图应用，再回退渲染组件。新应用要求渲染器 0.5.10，
因此不能在保留新应用时先将其依赖降级。回退取决于更新器保存的上一版本；
页面没有可用回退项或回退失败时应保留现场日志，由开发端检查恢复条件。
发布记录保留原包和哈希，不要求车主手动放置文件。

Beta 仅用于本次停车实测。Stable 晋升等待车主对同一批安装包的实际结果，
不得把离线检查或公开下载成功记录为实车验证。

## 离线验证与实际边界

`make -C native/cluster-render test` 运行真实服务、合成器和场景管理器，
显示后端为 fake GPU / fake DCSM。新增用例检查尺寸请求、普通地图恢复、
HUD 场景保持、总时限、租期、断流、显示中断、所有权及未知槽位拒绝。
应用的 `tools/test_underlay.js` 检查旧服务兼容性、分片协议、停车确认和
不重放预览；传入本机 `host_service` 路径还会检查真实 socket 交互。
`tools/test_page.js` 验证实际页面按钮和遮罩页面出现时的退出流程。

本机没有已发现的可运行 `mgu-emulator`，公开仓库检索也未定位到对应工程。
独立 Lima 构建虚拟机只用于 Ubuntu 18.04 / gcc 7.5 / x86-64 编译及 ABI
检查，不模拟 BMW HMI、KOMBI 或原厂告警。
没有执行完整车机模拟器安装、组件更新顺序或原厂显示合成验证。
主机用例通过不表示这些验证已经通过。
fake GPU 不编译真实 GPU 着色器；车机二进制的 ABI 检查也不证明网格已在
KOMBI GPU 上成功运行。着色器和原厂合成结果包含在下一次停车实测中。

## 下次停车实测的判定

记录标准和扩展两次网格的四边及中心位置：

| 观察结果 | 能支持的结论 |
| --- | --- |
| 扩展网格仍限制在中央，格子明显缩小 | 候选画布可能被整体缩放；不是两侧下层扩展 |
| 扩展边带消失、格子大小基本不变 | 可能被固定窗口裁切；需要结合中心偏移判断 |
| 扩展坐标到达两侧且原厂表盘保持在前 | 支持继续评估该布局的下层可见范围 |
| 黑屏、闪烁、错误或原厂内容异常 | 停止；不进入真实地图扩展阶段 |

还需检查：停止/到时后标准地图能恢复、HUD 表现、仪表模式变化，以及停车
可触发的原厂弹窗。静态网格不能验收行驶中的 ACC 和所有警告；这些能力
在获得相应证据前保持未验证。

基线和结束后的运行数据可由开发端直接读取。若没有 KOMBI 最终合成截图
接口，显示范围和遮挡仍需要现场观察或短视频；中控截图和源地图帧不能替代。
